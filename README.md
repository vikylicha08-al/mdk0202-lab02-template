# Практическая работа №2. Работа с виртуальной машиной. Установка операционной системы

## 🎯 Цель работы:
Получить практический опыт развертывания изолированных сред виртуализации, установки современной ОС и первичной диагностики оборудования через CLI.

## 📋 Техническое задание:
1. Используя гипервизор (VirtualBox / VMware / Hyper-V), создайте виртуальную машину со следующими характеристиками: CPU: 2 ядра, RAM: 2048 MB или выше, HDD/SSD: 25 GB. (Изходите из возможности вашей машины)
2. Выполните чистую установку операционной системы.
3. Внутри установленной ОС откройте консоль и выполните сбор информации о системе.
4. Результаты выполнения, логи и скриншоты занесите в файл отчета `report.md`.
